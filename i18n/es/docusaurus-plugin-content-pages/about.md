# Acerca de DIMO

DIMO es la infraestructura de datos vehiculares que impulsa la economía basada
en sesiones. Damos a los desarrolladores una sola API con permisos para acceder
a datos en tiempo real de vehículos de las más de 50 marcas ya conectadas a
DIMO, para que los equipos puedan crear aplicaciones de alquiler, pago por uso,
flotas, seguros e IA sin tener que integrar cada marca por su cuenta.

## Qué construimos

- **Funciona con cualquier marca:** una sola API para los datos vehiculares de
  las más de 50 marcas ya conectadas a DIMO, con telemetría normalizada en
  tiempo real, identidad vehicular y webhooks de eventos. DIMO opera
  integraciones directas como el
  [oráculo de Tesla](https://github.com/DIMO-Network/tesla-oracle), y puedes
  conectar cualquier otra fuente a partir del
  [ejemplo de oráculo](https://github.com/DIMO-Network/oracle-example). ¿Quieres
  una integración directa para tu marca? [Escríbenos](/contact).
- **Permisos desde el diseño:** los propietarios de vehículos otorgan y revocan
  el acceso mediante el modelo de consentimiento SACD. Los desarrolladores solo
  ven lo que un usuario compartió explícitamente. Está diseñado para cumplir con
  el RGPD y la Ley de Datos de la UE.
- **Listo para IA:** skills para agentes y flujos de datos accesibles por MCP
  para crear aplicaciones de IA sobre datos vehiculares reales.
- **Núcleo abierto:** el protocolo y las herramientas principales son de código
  abierto, así que no hay dependencia de un proveedor.

## Nuestra historia

DIMO se fundó en 2021 a partir de una frustración que conoce cualquiera que haya
lanzado un producto de vehículos conectados: los datos existen, pero llegar a
ellos implica un contrato distinto, una API distinta y un esquema de
consentimiento distinto para cada fabricante. La mayoría de los equipos pasan su
primer trimestre construyendo la infraestructura de integración en lugar de su
producto.

Así que construimos esa infraestructura una sola vez, de forma abierta. Los
conductores conectan sus propios autos a la red (más de 50 marcas hasta ahora),
y los desarrolladores obtienen una sola API con permisos para telemetría,
identidad y consentimiento. El protocolo y las herramientas principales son de
código abierto, lo que significa que cualquiera puede auditar cómo funciona
realmente el control de acceso en lugar de confiar en nuestra palabra.

Hoy DIMO impulsa alquileres, herramientas para flotas, productos de seguros,
apps de carga de VE y agentes de IA que actúan sobre datos vehiculares reales
con el permiso explícito y revocable del propietario.

## Reconocimientos

DIMO es finalista del premio Software-Defined Vehicle (SDV) 2026 de MotorTrend
Group, seleccionado junto a Tesla, Ford, GM y Mercedes-Benz.

**[Yevgeny "Yev" Khessin](https://www.linkedin.com/in/yevgeny-khessin/)** — CEO
y cofundador. Yev pasó más de una década construyendo sistemas de vehículos

su vida.

## Nuestra misión

Creemos que las personas que conducen los vehículos deben controlar los datos
que esos vehículos producen, y que la próxima generación de productos de
movilidad se construye con infraestructura abierta, no con jardines amurallados.
DIMO se fundó en 2021 para hacer realidad esa infraestructura.
