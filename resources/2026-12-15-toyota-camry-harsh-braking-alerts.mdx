To monitor harsh braking on a Toyota Camry, use the DIMO LTE R1, which reports harsh braking events for the car from model year 2007 and newer. You authenticate with your DIMO Developer License, exchange for a Vehicle JWT, and query events in the Telemetry API. The AutoPi connection for the Camry lists idling events only, so harsh braking comes from the DIMO LTE R1. DIMO gives developers API access to vehicle-state data: diagnostics, fault codes, battery and fuel health, odometer, and maintenance signals.

## Steps

1. Create a Developer License in the Developer Console and note your `Client ID`, `Redirect URI`, and `API Key`.
2. Get a Developer JWT, either the system-generated one in the Developer Console or one generated with your API key through a server SDK.
3. Have the owner share the Camry with your app through DIMO Connect. Vehicle owners consent to and control sharing, so builders get data with clear provenance. The Camry needs a DIMO LTE R1 for harsh braking events, since DIMO Events are only available on vehicles equipped with a DIMO LTE R1.
4. Exchange your Developer JWT for a Vehicle JWT through the Token Exchange API, using the vehicle's token ID and the permissions your app needs.
5. Send your Vehicle JWT in the `Authorization` header to the Telemetry API and query the `events` resource, filtering by the `behavior.harshBraking` tag.
6. Read each event's `timestamp`, `name`, `source`, `durationNs`, and `metadata` fields in your backend.

## Code

This GraphQL query goes to the Telemetry API with your Vehicle JWT in the `Authorization` header. The documentation excerpts do not include a full runnable snippet for this query, so the block is not tagged `test`. Replace `<vehicleTokenId>` with the Camry's token ID, and set `from` and `to` to the time range you want.

```graphql
query HarshBrakingEvents {
  events(
    tokenId: <vehicleTokenId>
    from: "2026-12-01T00:00:00Z"
    to: "2026-12-15T00:00:00Z"
    filter: { tags: { containsAny: ["behavior.harshBraking"] } }
  ) {
    timestamp
    name
    source
    durationNs
    metadata
  }
}
```

## FAQ

### Which Camry connection reports harsh braking?
The DIMO LTE R1 reports harsh braking events for the Toyota Camry from model year 2007 and newer. The AutoPi connection for the Camry lists idling events only.

### What does a harsh braking event describe?
The R1 Event Glossary defines HarshBraking as rapid deceleration detected by the device. These are risky events that the data source provider determines for the connected vehicle.

### Can I combine harsh braking events with other Camry signals?
Yes. The DIMO LTE R1 on the Camry also reports signals such as vehicle speed and coordinates, which you can query alongside events. DIMO adds vehicle-state depth on top of GPS tracking; it doesn't replace it. See the full signal list on [the Toyota Camry vehicle page](/vehicles/toyota/camry).

### Do I need a vehicle shared with me first?
Yes. You need a vehicle shared with you to fetch a Vehicle JWT, and sharing happens through DIMO Connect.
