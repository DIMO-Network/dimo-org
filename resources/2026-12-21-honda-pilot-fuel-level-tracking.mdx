To track fuel level and refuels on a Honda Pilot, authenticate, exchange for a Vehicle JWT, then query the Telemetry API: `signalsLatest` for the latest fuel signals and `segments` with `mechanism: refuel` for refuel segments. On a Pilot from model year 2009 and newer, the DIMO LTE R1 reports fuel percentage (`powertrainFuelSystemRelativeLevel`) and fuel level in liters (`powertrainFuelSystemAbsoluteLevel`), and it is the connection that supports refuel events.

DIMO gives developers API access to vehicle-state data: diagnostics, fault codes, battery and fuel health, odometer, and maintenance signals. Vehicle owners consent to and control sharing, so builders get data with clear provenance. See the [Honda Pilot vehicle page](/vehicles/honda/pilot) for the full signal list; this guide covers the fuel job only. The model-independent version is [How do I detect when a vehicle refuels with DIMO?](/resources/track-refuel-events)

## Steps

1. Create a Developer License in the [Developer Console](https://console.dimo.org/sign-in). Keep its Client ID, Redirect URI and API Key at hand.
2. Get a vehicle shared with you. Use DIMO Connect so the vehicle owner can consent to sharing. The Pilot needs a DIMO LTE R1 for the fuel signals and refuel events described here.
3. Get a Developer JWT for your Developer License in the Developer Console, or generate one with your API Key using a server SDK.
4. Exchange the Developer JWT for a Vehicle JWT by sending a request to the Token Exchange API with the vehicle's token ID. Request the permission for all-time, non-location data (privilege 1) and the permission for all-time location (privilege 4). The `segments` query requires both.
5. Read the current fuel state. Call the Telemetry API `signalsLatest` query with the Vehicle JWT as a Bearer token in the `Authorization` header, and request `powertrainFuelSystemRelativeLevel` (percent) and `powertrainFuelSystemAbsoluteLevel` (liters).
6. Find refuels over a time range. Call the `segments` query with `mechanism: refuel`. Refuel detection finds where fuel level rises significantly, and refuel segments include the level signal at the start and end by default. The maximum date range is 31 days.
7. Tune detection if needed. The `minIncreasePercent` setting in `config` sets the minimum percent increase in a window for it to count as a level increase. The default is 15.

## Code

Replace `12345` with your vehicle's token ID. This query reads both fuel signals:

```graphql
# Header: { "Authorization": "Bearer <yourVehicleJwt>" }

query GetLatestFuel {
  signalsLatest(tokenId: 12345) {
    powertrainFuelSystemRelativeLevel {
      value
      timestamp
    }
    powertrainFuelSystemAbsoluteLevel {
      value
      timestamp
    }
  }
}
```

This one lists refuels between two dates:

```graphql
query GetRefuels {
  segments(
    tokenId: 12345
    from: "2026-11-01T00:00:00Z"
    to: "2026-11-07T00:00:00Z"
    mechanism: refuel
    config: { minIncreasePercent: 15 }
    signalRequests: [
      { name: "powertrainFuelSystemRelativeLevel", agg: FIRST }
      { name: "powertrainFuelSystemRelativeLevel", agg: LAST }
    ]
  ) {
    start {
      timestamp
      value { latitude longitude }
    }
    end {
      timestamp
      value { latitude longitude }
    }
    duration
    isOngoing
    signals { name agg value }
  }
}
```

The next step is a Developer License from the [Developer Console](https://console.dimo.org/sign-in); after that, the [authentication guide](/docs/getting-started/authentication) shows the token flow.

## FAQ

### Which Honda Pilot connection reports fuel level?
The DIMO LTE R1 reports fuel percentage and fuel level in liters on a Honda Pilot, and it is the connection listed with refuel events. DIMO lists it for model year 2009 and newer.

### What is the difference between the two fuel signals?
`powertrainFuelSystemRelativeLevel` is reported as a percentage. `powertrainFuelSystemAbsoluteLevel` is reported in liters.

### Does the AutoPi report fuel level on a Honda Pilot?
The AutoPi connection for the Pilot lists trouble codes, low voltage battery voltage, altitude and coordinates. It does not list fuel signals, so use the DIMO LTE R1 for this job.

### Can I get location for each refuel?
Yes. Each segment returns start and end timestamps with latitude and longitude. The `segments` query needs the all-time location permission (privilege 4) on the Vehicle JWT in any case, alongside privilege 1. DIMO adds vehicle-state depth on top of GPS tracking; it doesn't replace it.

### How far back can one refuel query look?
The `segments` query has a maximum date range of 31 days. Use the `after` argument to paginate when a range returns more segments than the `limit`.
