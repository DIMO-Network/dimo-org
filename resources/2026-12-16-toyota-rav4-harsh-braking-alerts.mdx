On a Toyota RAV4, the DIMO LTE R1 reports harsh braking, so you can query those events through the DIMO Telemetry API. DIMO gives developers API access to vehicle-state data: diagnostics, fault codes, battery and fuel health, odometer, and maintenance signals. Harsh braking events for the RAV4 come from the DIMO LTE R1 (2007 and newer); the AutoPi connection listed for the RAV4 reports idling events, not harsh braking.

See the [Toyota RAV4 vehicle page](/vehicles/toyota/rav4) for the full signal list.

## Steps

1. Create a Developer License in the Developer Console and note your `Client ID`, `Redirect URI` and `API Key`. DIMO Events are only available on vehicles equipped with R1 LTE devices, so the RAV4 needs a DIMO LTE R1.
2. Get the RAV4 shared with your app using DIMO Connect. Vehicle owners consent to and control sharing, so builders get data with clear provenance.
3. Get a Developer JWT, either from the Developer Console or by using your API key with a server SDK.
4. Exchange the Developer JWT for a Vehicle JWT through the Token Exchange API. Request the permissions your app needs, and make sure the vehicle has been shared with you first.
5. Send the Vehicle JWT in the `Authorization` header to the Telemetry API at https://telemetry-api.dimo.zone.
6. Query `events` and filter by the `behavior.harshBraking` tag. Each event returns `timestamp`, `name`, `source`, `durationNs` and `metadata`.
7. Alert on the events in your backend. For example, check each result's `timestamp` and `source`, and send a notification from your own service.

## Code

This query is adapted from the Telemetry API events documentation. Replace `<vehicleTokenId>` with the token ID of the shared RAV4, and set the `Authorization` header to your Vehicle JWT. Further arguments such as a time range are not shown in the documentation excerpts used here, so they are left out.

```graphql
query HarshBrakingEvents {
  events(
    tokenId: <vehicleTokenId>
    tags: { containsAny: ["behavior.harshBraking"] }
  ) {
    timestamp
    name
    source
    durationNs
    metadata
  }
}
```

## FAQ

### Which Toyota RAV4 connection reports harsh braking?
The DIMO LTE R1 reports harsh braking on the RAV4. The AutoPi connection listed for the RAV4 reports idling events only.

### Which RAV4 model years does this cover?
The DIMO LTE R1 has been seen on RAV4 model years 2007 and newer.

### What does a harsh braking event mean?
The event glossary defines HarshBraking as rapid deceleration detected by the device. ExtremeBraking is a separate event type for extreme rapid deceleration.

### Can I filter events by type?
Yes. The `events` resource accepts a `tags` filter with operators such as `containsAny`, and `behavior.harshBraking` is one of the available tags.

### Does this replace GPS tracking?
No. DIMO adds vehicle-state depth on top of GPS tracking; it doesn't replace it.
