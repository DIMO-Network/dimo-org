To track fuel level and refuels on a Ford Escape, connect a supported DIMO device, get a Vehicle JWT, and query the Telemetry API with `signalsLatest` for fuel percentage and `segments` for refuel segments. On a Ford Escape, both the DIMO LTE R1 (2008 and newer) and AutoPi (2012 and newer) report fuel percentage as `powertrainFuelSystemRelativeLevel` and support refuel events. Neither device reports a liters signal on the Escape.

DIMO gives developers API access to vehicle-state data: diagnostics, fault codes, battery and fuel health, odometer, and maintenance signals. Vehicle owners consent to and control sharing, so builders get data with clear provenance. See the [Ford Escape vehicle page](/vehicles/ford/escape) for the full signal list. For any other vehicle, see [how to detect refuels](/resources/track-refuel-events).

## Steps

1. Create a Developer License in the [Developer Console](https://console.dimo.org/sign-in). You need your Client ID, Redirect URI and API Key.
2. Get the Escape shared with your app. Sharing is done through DIMO Connect, and you need a vehicle shared with you before you can fetch a Vehicle JWT.
3. Get a Developer JWT, either the system-generated one in the Developer Console or one generated with your API Key through a server SDK.
4. Exchange the Developer JWT for a Vehicle JWT through the Token Exchange API. Request the all-time, non-location data permission (privilege 1), which covers fuel data, and the all-time location permission (privilege 4). The `segments` query requires both.
5. Call the Telemetry API with the Vehicle JWT in the `Authorization` header, written as `Bearer <Vehicle JWT>`. Use `signalsLatest` to read the current `powertrainFuelSystemRelativeLevel` value, or `signals` to read it over a time range with an aggregation.
6. To find refuels, query `segments` with the `refuel` detection mechanism. Each segment marks a period where fuel level rises significantly. By default the minimum rise is 15 percent, and you can change it with `minIncreasePercent` in `config`. The maximum date range is 31 days.
7. Request `powertrainFuelSystemRelativeLevel` with `FIRST` and `LAST` aggregations in `signalRequests` if you want the explicit fuel level at the start and end of each refuel. The level signal at start and end is part of the default set for refuel segments.

## Code

Replace `12345` with your Escape's token ID. Query one returns the latest fuel percentage:

```graphql
# Send with header: { "Authorization": "Bearer <yourVehicleJwt>" }

query LatestFuel {
  signalsLatest(tokenId: 12345) {
    powertrainFuelSystemRelativeLevel {
      value
      timestamp
    }
  }
}
```

Query two returns the refuel segments for the date range:

```graphql
query FuelRefuels {
  segments(
    tokenId: 12345
    from: "2026-11-01T00:00:00Z"
    to: "2026-11-07T00:00:00Z"
    mechanism: refuel
    config: { minIncreasePercent: 15 }
    signalRequests: [
      { name: "powertrainFuelSystemRelativeLevel", agg: FIRST }
      { name: "powertrainFuelSystemRelativeLevel", agg: LAST }
    ]
  ) {
    start {
      timestamp
    }
    end {
      timestamp
    }
    duration
    isOngoing
    signals { name agg value }
  }
}
```

Set up your own access by creating a Developer License in the [Developer Console](https://console.dimo.org/sign-in) and following the [authentication guide](/docs/getting-started/authentication).

## FAQ

### Which Ford Escape connections report fuel level?
The DIMO LTE R1 and AutoPi both report fuel percentage as `powertrainFuelSystemRelativeLevel`. Both also support refuel events.

### Do I need hardware to get fuel data from an Escape?
Yes. The fuel data described here comes from a DIMO LTE R1 or an AutoPi installed in the vehicle.

### What counts as a refuel?
A refuel segment is detected where fuel level rises significantly. The default minimum increase is 15 percent, and you can set a different value with `minIncreasePercent`.

### How far back can I query refuels?
The `segments` query has a maximum date range of 31 days per request. Use `limit` and `after` to page through results.

### Can I read the fuel level over time instead of only the latest value?
Yes. Use the `signals` query with a `from`, `to`, and `interval`, and include an aggregation type such as `LAST` on the fuel signal.
