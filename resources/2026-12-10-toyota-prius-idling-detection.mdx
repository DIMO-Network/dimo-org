To detect idling on a Toyota Prius, query the DIMO Telemetry API for segments with the idling detection mechanism. On a Toyota Prius, both the AutoPi (2008–2020) and the DIMO LTE R1 (2009 and newer) report engine RPM (`powertrainCombustionEngineSpeed`) and support idling detection. Idle segments are contiguous periods where engine RPM stays in the idle range, and they require a DIMO device. See the [Toyota Prius vehicle page](/vehicles/toyota/prius) for the full signal list. For any other vehicle, see [how to detect vehicle idling](/resources/detect-vehicle-idling).

DIMO gives developers API access to vehicle-state data: diagnostics, fault codes, battery and fuel health, odometer, and maintenance signals.

## Steps

1. Get your Developer JWT. You need the Client ID, Redirect URI and API Key from your Developer License. You can use the system-generated Developer JWT in the [Developer Console](https://console.dimo.org/sign-in), or generate one with your API key.
2. Get the Prius shared with you. You need a vehicle shared with you before you can fetch a Vehicle JWT. Sharing is handled through DIMO Connect, so the owner consents to it.
3. Exchange your Developer JWT for a Vehicle JWT by sending a request to the Token Exchange API with the vehicle's token ID. The `segments` query requires privilege 1 (all-time, non-location data) and privilege 4 (all-time location), so request both.
4. Send the Vehicle JWT in the `Authorization` header of a request to the Telemetry API.
5. Query `segments` with the idling detection mechanism. Set `from` and `to` (the maximum range is 31 days) and, if needed, tune the idle thresholds in `config`.
6. Read each segment's `start`, `end` and `duration`. If `isOngoing` is true, the segment extends beyond your query range and `end` is not included.

## Code

```graphql
query GetIdlingSegments {
  segments(
    tokenId: 12345
    from: "2026-11-01T00:00:00Z"
    to: "2026-11-07T00:00:00Z"
    mechanism: idling
    config: {
      maxIdleRpm: 1000
      minSegmentDurationSeconds: 240
    }
    signalRequests: [
      { name: "powertrainCombustionEngineSpeed", agg: MAX }
    ]
    limit: 50
  ) {
    start {
      timestamp
      value { latitude longitude }
    }
    end {
      timestamp
      value { latitude longitude }
    }
    duration
    isOngoing
    startedBeforeRange
    signals { name agg value }
  }
}
```

Replace `12345` with your Prius's vehicle token ID. Send the Vehicle JWT as `{ "Authorization": "Bearer <yourVehicleJwt>" }`.

Need credentials first? The [Developer Console](https://console.dimo.org/sign-in) issues the Developer License, and the [authentication guide](/docs/getting-started/authentication) covers both JWTs.

## FAQ

### Which devices support idling detection on a Toyota Prius?
The AutoPi (2008–2020) and the DIMO LTE R1 (2009 and newer) both report engine RPM for the Prius and support idling detection. Idle segments require a DIMO device.

### What counts as idle?
Idle segments are contiguous periods where engine RPM remains in the idle range. By default, windows with a maximum RPM at or below 1000 are considered idle.

### How do I make detection more or less sensitive?
Adjust `maxIdleRpm` (minimum 300, maximum 3000) and `signalCountThreshold` in `config`. Higher `signalCountThreshold` values are more conservative and lower values are more sensitive.

### How do I filter out very short idle periods?
Set `minSegmentDurationSeconds` in `config`. It defaults to 240 seconds, with a minimum of 60 and a maximum of 3600.
