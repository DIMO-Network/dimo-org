To verify mileage on a Tesla Model Y, read the odometer signal reported by the Tesla connection, then ask DIMO to generate an odometer statement attestation for the vehicle. DIMO gives developers API access to vehicle-state data: diagnostics, fault codes, battery and fuel health, odometer, and maintenance signals. Vehicle owners consent to and control sharing, so builders get data with clear provenance.

On a Tesla Model Y from 2020 and newer, the DIMO Tesla connection reports odometer in km. See the full signal list on the [Tesla Model Y vehicle page](/vehicles/tesla/model-y).

## Steps

1. Create a developer license in the Developer Console and gather your `Client ID`, `Redirect URI` and `API Key`.
2. Get the Model Y shared with your app through DIMO Connect. A vehicle must be shared with you before you can fetch a Vehicle JWT. Request the permission for all-time, non-location data, which covers the odometer.
3. Get a Developer JWT using your API key, for example with a DIMO server SDK.
4. Exchange the Developer JWT for a Vehicle JWT through the Token Exchange API, passing the vehicle's token ID and the permissions you need.
5. Call the Attestation API odometer statement endpoint, `POST /v2/attestation/odometer-statement/:tokenId`, with the Vehicle JWT. The `timestamp` parameter is optional.
6. Read the latest odometer value from the Telemetry API with `signalsLatest`, using the `powertrainTransmissionTravelledDistance` signal, and compare it with the attested statement. Use the `rawVC` returned from the attestation to query the Telemetry API for the statement itself.

## Code

This example is adapted from the Attestation API and Telemetry API documentation. Replace the placeholders with your Vehicle JWT and the vehicle's token ID. Run the attestation request first, then the query.

```shell
# 1. Generate an odometer statement attestation
curl -X POST "https://attestation-api.dimo.zone/v2/attestation/odometer-statement/<TOKEN_ID>" \
  -H "Authorization: Bearer <VEHICLE_JWT>" \
  -H "Content-Type: application/json" \
  -d '{
    "timestamp": "2023-01-01T00:00:00Z"
  }'
```

```graphql
# 2. Read the latest odometer value (Telemetry API)
# Header: { "Authorization": "<yourVehicleJwt>" }
query GetLatestOdometer {
  signalsLatest(tokenId: 12345) {
    powertrainTransmissionTravelledDistance {
      value
      timestamp
    }
  }
}
```

## FAQ

### Which Model Y signal carries the mileage?
The DIMO Tesla connection reports odometer as `powertrainTransmissionTravelledDistance`, in km.

### Does the owner need to share the car first?
Yes. You need a vehicle shared with you to fetch a Vehicle JWT, and the owner controls what is shared. Sharing is done through DIMO Connect.

### What does the odometer statement attestation give me?
The Attestation API generates an attestation for the vehicle's odometer. After you get the `rawVC` from the response, you can query the Telemetry API for it.

### Is the timestamp required?
No. The `timestamp` parameter on the odometer statement request is optional.
