To get check-engine alerts for a Ram 1500, connect a DIMO device, have the owner share the vehicle with your app, and read trouble codes through the DIMO Telemetry API. DIMO gives developers API access to vehicle-state data: diagnostics, fault codes, battery and fuel health, odometer, and maintenance signals. On a Ram 1500, the DIMO LTE R1 (2013 and newer) and the AutoPi (2012 and newer) both report diagnostic trouble codes and distance driven with the warning light on.

Vehicle owners consent to and control sharing, so builders get data with clear provenance. Full signal coverage is on the [Ram 1500 vehicle page](/vehicles/ram/1500).

## Steps

1. Connect hardware. The Ram 1500 needs a DIMO LTE R1 or an AutoPi to report data. Without one, there is no data to read.
2. Get the vehicle shared with your app. Use DIMO Connect so the owner can log in and choose to share the vehicle with your Developer License.
3. Get a Developer JWT in the Developer Console, either the system-generated one or one generated with your API key.
4. Exchange it for a Vehicle JWT with the Token Exchange API, sending the vehicle token ID and requesting a permission such as all-time, non-location data. The vehicle must already be shared with you.
5. Query the Telemetry API with the Vehicle JWT in the `Authorization` header. Use `signalsLatest` to read the most recent `obdDTCList` and `obdDistanceWithMIL` values. Check the list for new codes on each poll.
6. For push alerts instead of polling, use the Vehicle Triggers API (webhooks, currently in public beta). Call `GET /v1/webhooks/signals` to see which signal names can be used, create a webhook with your `targetURL`, `condition` and `coolDownPeriod`, then subscribe the vehicle. DIMO sends a `POST` to your URL when the condition is met.

## Code

This query is adapted from the `signalsLatest` example in the Telemetry API documentation. Replace the token ID with your vehicle's token ID.

```graphql
query GetCheckEngineSignals {
  signalsLatest(tokenId: 12345) {
    obdDTCList {
      value
      timestamp
    }
    obdDistanceWithMIL {
      value
      timestamp
    }
  }
}
```

## FAQ

### Which device reports trouble codes on a Ram 1500?
Both the DIMO LTE R1 and the AutoPi report `obdDTCList` and `obdDistanceWithMIL`, and both list new trouble codes as an event.

### Is there a DTC count signal?
The DIMO LTE R1 reports `obdStatusDTCCount` on a Ram 1500. The AutoPi does not list it, but it does report `obdDistanceSinceDTCClear` and `obdWarmupsSinceDTCClear`, which the DIMO LTE R1 does not list.

### Does DIMO report the check-engine lamp state directly?
No lamp on/off signal is listed for this truck. The distance driven with the warning light on is reported as `obdDistanceWithMIL`.

### Do I need the owner's permission?
Yes. You need a Vehicle JWT, and fetching one requires the vehicle to be shared with your Developer License.
