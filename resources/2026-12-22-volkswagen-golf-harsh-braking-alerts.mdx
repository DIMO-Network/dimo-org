To monitor harsh braking on a Volkswagen Golf, query the DIMO Telemetry API for harsh braking events. On a Volkswagen Golf, the DIMO LTE R1 reports harsh braking, for model year 2009 and newer. The AutoPi connection listed for the Golf reports idling only, so it does not provide harsh braking. DIMO gives developers API access to vehicle-state data: diagnostics, fault codes, battery and fuel health, odometer, and maintenance signals.

## Steps

1. Create a developer license in the Developer Console and generate an API key. You will need your Client ID, Redirect URI and API Key.
2. Get the Golf shared with your app through DIMO Connect. A vehicle must be shared with you before you can fetch a Vehicle JWT. Vehicle owners consent to and control sharing, so builders get data with clear provenance.
3. Confirm the Golf has a DIMO LTE R1. DIMO Events are only available on vehicles equipped with a DIMO LTE R1, and the documentation lists HarshBraking as an R1 event: rapid deceleration detected by the device.
4. Get a Developer JWT, then exchange it for a Vehicle JWT through the Token Exchange API. Request the permissions your use case needs.
5. Call the `events` resource in the Telemetry API with your Vehicle JWT. Filter by the tag `behavior.harshBraking` so you only get harsh braking events.
6. Read `timestamp`, `durationNs`, `source` and `metadata` from each event. Use `source` to see which connection created the event.

DIMO adds vehicle-state depth on top of GPS tracking; it doesn't replace it.

## Code

This GraphQL query returns harsh braking events for one vehicle. Send it to the Telemetry API at https://telemetry-api.dimo.zone with the header `{ "Authorization": "<yourVehicleJwt>" }`. Replace `<vehicleTokenId>` with the Golf's token ID.

```graphql
query GetHarshBraking {
  events(
    tokenId: <vehicleTokenId>
    from: "2026-12-01T00:00:00Z"
    to: "2026-12-22T00:00:00Z"
    filter: { tags: { containsAny: ["behavior.harshBraking"] } }
  ) {
    timestamp
    name
    source
    durationNs
    metadata
  }
}
```

The `tokenId`, `from`, `to` and `filter` argument names on this query are adapted from the `events` argument list and tag filter in the documentation; check the Telemetry API explorer for the exact schema before you ship.

## FAQ

### Which Volkswagen Golf connection reports harsh braking?
The DIMO LTE R1 reports harsh braking on the Golf, for model year 2009 and newer. The AutoPi connection listed for the Golf reports idling only.

### What does a harsh braking event describe?
The documentation defines HarshBraking as rapid deceleration detected by the device. The R1 also has related event types for extreme braking, harsh acceleration and harsh cornering, but this guide covers harsh braking only.

### Do I need a Vehicle JWT to read events?
Yes. You get a Developer JWT first, then exchange it for a Vehicle JWT for a specific vehicle through the Token Exchange API. The vehicle must be shared with you.

### Where can I see everything the Golf reports?
The full list of signals and connections is on the [Volkswagen Golf vehicle page](/vehicles/volkswagen/golf).
