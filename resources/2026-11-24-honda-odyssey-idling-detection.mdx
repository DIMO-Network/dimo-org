To detect idling on a Honda Odyssey, query idling segments in the DIMO Telemetry API. On a Honda Odyssey, the DIMO LTE R1 (2011 and newer) reports engine RPM, vehicle speed and ignition status, and supports idling and harsh braking events. DIMO gives developers API access to vehicle-state data: diagnostics, fault codes, battery and fuel health, odometer, and maintenance signals.

The AutoPi device listed for the Odyssey reports low voltage battery, altitude and coordinates, and no events, so use the DIMO LTE R1 for this job. Details on the car are on [the Honda Odyssey vehicle page](/vehicles/honda/odyssey).

## Steps

1. Get your Developer License credentials (`Client ID`, `Redirect URI` and `API Key`) from the Developer Console, then obtain a Developer JWT.
2. Have the owner share the Odyssey with your app through DIMO Connect. Vehicle owners consent to and control sharing, so builders get data with clear provenance. You need a shared vehicle to fetch a Vehicle JWT.
3. Exchange the Developer JWT for a Vehicle JWT using the Token Exchange API. Request the permission for all-time, non-location data (privilege 1).
4. Call the Telemetry API `segments` query with the vehicle token ID, a time range of up to 31 days, and `mechanism: idling`. The idling mechanism requires a DIMO device.
5. Tune detection with `config`. `maxIdleRpm` sets the upper RPM bound for idle (default 1000, min 300, max 3000). `minSegmentDurationSeconds` filters short segments (default 240 seconds). `signalCountThreshold` sets how sensitive activity detection is (default 10).
6. Read each returned segment's `start`, `end`, `duration` and `isOngoing` fields. If `isOngoing` is true, the segment extends past your query range and `end` is not returned.
7. Optionally add `signalRequests` to aggregate signals per segment, such as `speed` with `MAX`. The Odyssey's DIMO LTE R1 reports `speed`.

## Code

This query is adapted from the Telemetry API segments example. It uses the idling mechanism and the `speed` signal. Send it with your Vehicle JWT in the `Authorization` header.

```graphql
query GetIdlingSegments {
  segments(
    tokenId: 117315
    from: "2025-11-01T09:21:19Z"
    to: "2025-11-07T09:21:19Z"
    mechanism: idling
    config: { maxIdleRpm: 1000, minSegmentDurationSeconds: 240 }
    signalRequests: [
      { name: "speed", agg: MAX }
    ]
    limit: 50
  ) {
    start {
      timestamp
      value { latitude longitude }
    }
    end {
      timestamp
      value { latitude longitude }
    }
    duration
    isOngoing
    startedBeforeRange
    signals { name agg value }
  }
}
```

## FAQ

### Which device detects idling on a Honda Odyssey?
The DIMO LTE R1 reports engine RPM and supports idling events on the Odyssey. The idling mechanism requires a DIMO device.

### How does DIMO decide a segment is idling?
Idling segments are contiguous periods where engine RPM stays in the idle range. You set the upper bound with `maxIdleRpm`, which defaults to 1000.

### How far back can I query?
The `segments` query has a maximum date range of 31 days. Returns default to 100 segments, with a maximum of 200 per request, and you can paginate with `after`.

### Does this replace GPS tracking?
No. DIMO adds vehicle-state depth on top of GPS tracking; it doesn't replace it.
