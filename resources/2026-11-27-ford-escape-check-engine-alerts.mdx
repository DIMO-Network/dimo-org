To get check-engine alerts on a Ford Escape, use a DIMO Vehicle Triggers webhook to get pushed updates and read the diagnostic trouble codes through the Telemetry API. On a Ford Escape, both the DIMO LTE R1 (2008 and newer) and AutoPi (2012 and newer) report diagnostic trouble codes and distance with MIL on, and the DIMO LTE R1 also reports DTC count. Every signal for this car is on the [Ford Escape vehicle page](/vehicles/ford/escape). For any other vehicle, see [how to get check-engine light alerts](/resources/check-engine-light-alerts).

DIMO gives developers API access to vehicle-state data: diagnostics, fault codes, battery and fuel health, odometer, and maintenance signals. Vehicle owners consent to and control sharing, so builders get data with clear provenance.

## Steps

1. Create a Developer License in the [Developer Console](https://console.dimo.org/sign-in) and note the Client ID, Redirect URI and API Key. Have the vehicle owner share the Ford Escape with your app through DIMO Connect.
2. Get a Developer JWT. You use it for every webhook call.
3. To receive pushed updates instead of polling, create a webhook with the Vehicle Triggers API. Confirm the signal name with `GET /v1/webhooks/signals` first. Use `signals` as the `service` and set `metricName` to `vss.obdDistanceWithMIL`, which both Escape devices report, or to `vss.obdStatusDTCCount` on a DIMO LTE R1, with the condition `valueNumber > 0`. Also set a `description` and a `status` of `enabled`, and register a `targetURL`, a `verificationToken` and a `coolDownPeriod`.
4. Subscribe the vehicle to the webhook, either one vehicle at a time by the vehicle's DID (`did:erc721:137:0xbA5738a18d83D41847dfFbDC6101d37C69c9B0cF:12345` is an example) or all vehicles that have shared permissions with your Developer License. When the condition is met, DIMO sends a `POST` request to your `targetURL`.
5. Exchange the Developer JWT for a Vehicle JWT for that vehicle using the Token Exchange API. Request privilege 1, the all-time, non-location data permission.
6. Query the Telemetry API with `signalsLatest` to read the latest diagnostic trouble codes. On a Ford Escape, `obdDTCList` is reported by both the DIMO LTE R1 and AutoPi. `obdDistanceWithMIL` is also reported by both, and `obdStatusDTCCount` is reported by the DIMO LTE R1.

Choose the trigger with the signal meanings in mind: `obdDistanceWithMIL` measures distance travelled with the malfunction indicator lamp (MIL) on, and `obdStatusDTCCount` counts the diagnostic trouble codes that are currently active.

## Code

First create the webhook, authenticated with the Developer JWT. Put your own endpoint and verification token in the body.

```shell
curl -X POST "https://vehicle-triggers-api.dimo.zone/v1/webhooks" \
  -H "Authorization: Bearer <DEV_JWT>" \
  -H "Content-Type: application/json" \
  -d '{
    "service": "signals",
    "metricName": "vss.obdDistanceWithMIL",
    "condition": "valueNumber > 0",
    "coolDownPeriod": 3600,
    "description": "Fires when a subscribed Escape reports distance travelled with the MIL on",
    "displayName": "Escape check-engine alert",
    "targetURL": "https://example.com/webhook-receiver",
    "status": "enabled",
    "verificationToken": "<YOUR_VERIFICATION_TOKEN>"
  }'
```

This query reads the latest check-engine related signals for a Ford Escape. Replace `12345` with your vehicle's token ID and send your Vehicle JWT in the `Authorization` header as `Bearer <Vehicle JWT>`.

```graphql
query GetCheckEngineSignals {
  signalsLatest(tokenId: 12345) {
    obdDTCList {
      value
      timestamp
    }
    obdDistanceWithMIL {
      value
      timestamp
    }
  }
}
```

From here, register for a Developer License in the [Developer Console](https://console.dimo.org/sign-in), then read the [authentication guide](/docs/getting-started/authentication) and the [Vehicle Triggers API reference](/docs/api-references/vehicle-triggers-api).

## FAQ

### Which Ford Escape hardware reports trouble codes?
The DIMO LTE R1 and AutoPi both report diagnostic trouble codes on a Ford Escape. The DIMO LTE R1 supports Escape model years 2008 and newer, and the AutoPi 2012 and newer.

### Do I need hardware to get these alerts?
Yes. The signals described here come from a DIMO LTE R1 or an AutoPi connected to the Ford Escape.

### Can I be pushed an alert instead of polling?
Yes. Vehicle Triggers webhooks send a `POST` request to your endpoint when a vehicle meets the condition you configure, so you don't need to poll the API. Webhooks are in public beta.

### Where can I see every signal for this car?
The full list is on the [Ford Escape vehicle page](/vehicles/ford/escape).
