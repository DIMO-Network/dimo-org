To detect idling on a Ford F-150, query the DIMO Telemetry API for idling segments using a Vehicle JWT for that truck. On an F-150, both the DIMO LTE R1 (model year 2009 and newer) and the AutoPi (2010 and newer) report engine RPM and list idling as an event. Idle detection requires a DIMO device. See the [Ford F-150 vehicle page](/vehicles/ford/f-150) for full coverage.

## Steps

1. Get a Developer JWT for your Developer License, either system-generated in the Developer Console or generated with your API key.
2. Have the F-150 shared with your app. You need a shared vehicle to fetch a Vehicle JWT, and DIMO Connect handles vehicle sharing.
3. Exchange your Developer JWT for a Vehicle JWT by sending a request to the Token Exchange API for that vehicle's token ID.
4. Send the Vehicle JWT in the `Authorization` header of a Telemetry API request.
5. Call the `segments` query with the idling detection mechanism and a time range of at most 31 days. Idle segments are contiguous periods where engine RPM stays in the idle range.
6. Tune detection with `config`. `maxIdleRpm` sets the idle RPM upper bound (default 1000), and `minSegmentDurationSeconds` filters out short segments (default 240).
7. Read `start`, `end`, `duration` and `isOngoing` from each segment. Add a `signalRequests` entry such as `powertrainCombustionEngineSpeed` with a MAX aggregation to see the highest engine RPM in each idle period.

## Code

```graphql
# Header: { "Authorization": "<yourVehicleJwt>" }
query GetIdlingSegments {
  segments(
    tokenId: 117315
    from: "2025-11-01T09:21:19Z"
    to: "2025-11-07T09:21:19Z"
    mechanism: idling
    config: { maxIdleRpm: 1000, minSegmentDurationSeconds: 240 }
    signalRequests: [
      { name: "powertrainCombustionEngineSpeed", agg: MAX }
    ]
    limit: 50
  ) {
    start {
      timestamp
      value { latitude longitude }
    }
    end {
      timestamp
      value { latitude longitude }
    }
    duration
    isOngoing
    startedBeforeRange
    signals { name agg value }
  }
}
```

Replace `117315` with your F-150's vehicle token ID and adjust the time range.

## FAQ

### Which F-150 devices support idle detection?
The DIMO LTE R1 and the AutoPi both list idling as an event for the F-150 and report engine RPM. Idle detection requires a DIMO device.

### What counts as idling?
An idle segment is a contiguous period where engine RPM stays in the idle range. By default, windows with a maximum RPM at or below 1000 count as idle, and you can change this with `maxIdleRpm`.

### Why are short idle periods missing from my results?
Segments shorter than `minSegmentDurationSeconds` are filtered out. The default is 240 seconds, and the minimum you can set is 60.

### How far back can I query?
The maximum date range for one `segments` query is 31 days. Results return up to 100 segments by default, with a maximum of 200, and you page through them with `after`.
