To get harsh braking events on a Honda CR-V, connect the car with a DIMO LTE R1 and query its harsh braking events through the DIMO Telemetry API. DIMO supports harsh braking events on the CR-V through the DIMO LTE R1 for model year 2008 and newer. Vehicle owners consent to and control sharing, so builders get data with clear provenance.

The AutoPi reports an idling event but not harsh braking on the CR-V, so use the DIMO LTE R1 for this job. See the full signal list on the [Honda CR-V vehicle page](/vehicles/honda/cr-v). For any other vehicle, see [how to detect harsh braking](/resources/detect-harsh-braking).

## Steps

1. Create a Developer License in the [Developer Console](https://console.dimo.org/sign-in) and gather your `Client ID`, `Redirect URI` and `API Key`.
2. Get a Developer JWT, either the system-generated one in the Developer Console or one generated with your API key through a server SDK.
3. Get the CR-V shared with your app through DIMO Connect. A vehicle must be shared with you before you can fetch a Vehicle JWT.
4. Send a request to the Token Exchange API with the vehicle's token ID to exchange your Developer JWT for a Vehicle JWT. Ask for privilege 1 (all-time, non-location data) and privilege 4 (all-time location), because the `events` query requires both. The Vehicle JWT is valid for a short time and for one vehicle only.
5. Send the Vehicle JWT in the `Authorization` header of a Telemetry API request, written as `Authorization: Bearer <Vehicle JWT>`.
6. Query the `events` resource with the required `tokenId`, `from` and `to` arguments, and filter by the `behavior.harshBraking` tag inside `filter`. Each event returns a timestamp, name, source, duration in nanoseconds and metadata.
7. If you want DIMO to push each alert to you, register a [Vehicle Triggers](/docs/api-references/vehicle-triggers-api) webhook whose `service` is `events` and whose `metricName` is `behavior.harshBraking`, and subscribe the CR-V to that webhook.

## Code

Send this query to the Telemetry API with your Vehicle JWT in the `Authorization` header. Replace `12345` with your vehicle's token ID and adjust the `from` and `to` timestamps.

```graphql
query HarshBrakingEvents {
  events(
    tokenId: 12345
    from: "2026-11-01T00:00:00Z"
    to: "2026-11-07T00:00:00Z"
    filter: { tags: { containsAny: ["behavior.harshBraking"] } }
  ) {
    timestamp
    name
    source
    durationNs
    metadata
  }
}
```

To try this on a CR-V, sign in to the [Developer Console](https://console.dimo.org/sign-in) for a Developer License and then read the [authentication guide](/docs/getting-started/authentication).

## FAQ

### Which connection reports harsh braking on a Honda CR-V?
The DIMO LTE R1 does. DIMO Events are only available on vehicles equipped with a DIMO LTE R1.

### What does a harsh braking event mean?
It is rapid deceleration detected by the device. Events are pre-defined by the data connection, so the source provider determines what counts as a risky event.

### What does each event return?
Each event has a timestamp, a name, the source connection that created it, a duration in nanoseconds and optional metadata.

### Do I need a Vehicle JWT?
Yes. A Developer JWT does not give access to vehicle data, so you exchange it for a Vehicle JWT for the specific vehicle once the owner has shared it with you.
