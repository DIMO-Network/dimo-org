To track fuel level and refuels on a Honda Odyssey, connect the car with a DIMO LTE R1, get a Vehicle JWT, then query fuel signals with `signalsLatest` and refuel segments with `segments` from the Telemetry API. On a Honda Odyssey from model year 2011 and newer, the DIMO LTE R1 reports fuel percentage (`powertrainFuelSystemRelativeLevel`) and fuel level in liters (`powertrainFuelSystemAbsoluteLevel`), and refuel detection is listed for that device.

DIMO gives developers API access to vehicle-state data: diagnostics, fault codes, battery and fuel health, odometer, and maintenance signals. Vehicle owners consent to and control sharing, so builders get data with clear provenance. The full signal list is on the [Honda Odyssey vehicle page](/vehicles/honda/odyssey). A general guide that works for other vehicles is here: [How do I detect when a vehicle refuels with DIMO?](/resources/track-refuel-events)

## Steps

1. Create a Developer License in the [Developer Console](https://console.dimo.org/sign-in). It gives you a Client ID, Redirect URI and API Key.
2. Get the Odyssey shared with your app through DIMO Connect. The car needs a DIMO LTE R1 for the fuel signals and refuel detection described here.
3. Get a Developer JWT, then exchange it at the Token Exchange API for a Vehicle JWT for that vehicle. The Vehicle JWT is short-lived and scoped to one vehicle. Request the all-time, non-location data permission (privilege 1) together with all-time location (privilege 4); `segments` requires both.
4. To read the current fuel state, query `signalsLatest` in the Telemetry API for `powertrainFuelSystemRelativeLevel` (fuel percentage, %) and `powertrainFuelSystemAbsoluteLevel` (fuel level, liters). Send the Vehicle JWT as `Authorization: Bearer <Vehicle JWT>`.
5. To find refuels, query `segments` with `mechanism: refuel` over a date range of up to 31 days. Each segment is a period where fuel level rises significantly. By default, a refuel segment also includes the level signal at its start and end.
6. Optionally tune detection with `minIncreasePercent` in `config`. The default is 15, which is the minimum percent increase within a window to count as a level increase.
7. Page through results with `limit` (default 100, max 200) and `after`.

## Code

This GraphQL query returns refuel segments for one Odyssey over a week, with the fuel percentage at the start and end of each segment. Replace `12345` with your vehicle's token ID, change the dates, and send your Vehicle JWT as a Bearer token in the `Authorization` header.

```graphql
query GetRefuels {
  segments(
    tokenId: 12345
    from: "2026-11-01T00:00:00Z"
    to: "2026-11-07T00:00:00Z"
    mechanism: refuel
    config: { minIncreasePercent: 15 }
    signalRequests: [
      { name: "powertrainFuelSystemRelativeLevel", agg: FIRST }
      { name: "powertrainFuelSystemRelativeLevel", agg: LAST }
    ]
    limit: 50
  ) {
    start {
      timestamp
      value { latitude longitude }
    }
    end {
      timestamp
    }
    duration
    isOngoing
    signals { name agg value }
  }
}
```

From here, create a Developer License in the [Developer Console](https://console.dimo.org/sign-in) and use the [authentication guide](/docs/getting-started/authentication) to get a Vehicle JWT for the Odyssey.

## FAQ

### Which Honda Odyssey connection reports fuel level?
The DIMO LTE R1 reports fuel percentage and fuel level in liters, and refuel detection is listed for it. The AutoPi connection listed for the Odyssey reports low voltage battery, altitude and coordinates, not fuel.

### Which model years are supported?
The DIMO LTE R1 is listed from model year 2011 and newer. AutoPi is listed from 2010 and newer, but it does not report fuel signals for this car.

### How do I get the latest fuel reading instead of refuel segments?
Use `signalsLatest` with `powertrainFuelSystemRelativeLevel` or `powertrainFuelSystemAbsoluteLevel` and request `value` and, optionally, `timestamp`.
