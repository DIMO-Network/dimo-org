To verify Tesla Model X mileage with DIMO, read the odometer signal for the vehicle and request an odometer statement attestation for it. On a Tesla Model X (2016 and newer), the Tesla OEM cloud connection reports the odometer in kilometers. DIMO gives developers API access to vehicle-state data: diagnostics, fault codes, battery and fuel health, odometer, and maintenance signals. Vehicle owners consent to and control sharing, so builders get data with clear provenance.

See the full signal list on the [Tesla Model X vehicle page](/vehicles/tesla/model-x).

## Steps

1. Create a Developer License in the Developer Console and generate an API key. You need your Client ID, Redirect URI and API key.
2. Get a vehicle shared with your app. The owner shares the Model X through DIMO Connect, and you need the vehicle's token ID.
3. Get a Developer JWT, then exchange it for a Vehicle JWT through the Token Exchange API. Request the permission for all-time, non-location data, which is the permission the odometer signal falls under.
4. Read the current odometer with the Telemetry API `signalsLatest` query and the `powertrainTransmissionTravelledDistance` signal. On the Model X this signal is reported in km by the Tesla OEM cloud connection.
5. Request an odometer statement attestation with the Attestation API (`POST /v2/attestation/odometer-statement/:tokenId`), sending the Vehicle JWT. The `timestamp` parameter is optional.
6. Retrieve the resulting verifiable credential through the Telemetry API, as described in the Attestation API documentation.

## Code

This example requests an odometer statement attestation for a vehicle. It assumes you already have a Vehicle JWT and the vehicle's token ID, so it is not tagged as runnable.

```typescript
const odometerVc = await dimo.attestation.createOdometerStatementVC({
  vehicleJwt: "eyJhbGc...ILlujqw",
  tokenId: 123456,
  timestamp: '2023-01-01T00:00:00Z' // Optional
})
```

To read the latest odometer value for the same vehicle, send this query to the Telemetry API with the Vehicle JWT in the `Authorization` header:

```graphql
query GetLatestOdometer {
  signalsLatest(tokenId: 123456) {
    powertrainTransmissionTravelledDistance {
      value
      timestamp
    }
  }
}
```

## FAQ

### Which signal gives the Model X odometer?
The Tesla OEM cloud connection reports `powertrainTransmissionTravelledDistance`, labeled Odometer, in km.

### Do I need the owner's permission?
Yes. A vehicle must be shared with you before you can fetch a Vehicle JWT, and the owner controls what is shared.

### Is the timestamp parameter required for the odometer statement?
No. In the Attestation API documentation, `timestamp` is optional for the odometer statement request.

### Can I read historical odometer values?
The Telemetry API `signals` query retrieves signal data for a given time period, using `from`, `to` and `interval` arguments.
