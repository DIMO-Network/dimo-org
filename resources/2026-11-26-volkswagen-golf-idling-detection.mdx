To detect idling on a Volkswagen Golf, query the DIMO Telemetry API for segments using the `idling` detection mechanism. Idle segments are contiguous periods where engine RPM stays in the idle range, and the mechanism requires a DIMO device. On a Volkswagen Golf, both the DIMO LTE R1 (2009 and newer) and AutoPi (2008 and newer) support idling, and both report engine RPM (`powertrainCombustionEngineSpeed`) and vehicle speed (`speed`). See the [Volkswagen Golf vehicle page](/vehicles/volkswagen/golf) for the full list of signals.

DIMO adds vehicle-state depth on top of GPS tracking; it doesn't replace it. Vehicle owners consent to and control sharing, so builders get data with clear provenance.

## Steps

1. Get a Developer JWT. You need your `Client ID`, `Redirect URI` and `API Key` from the Developer Console. You can use the system-generated Developer JWT, or generate one with your API key through a server SDK.
2. Get the Golf shared with your app. You need a vehicle shared with you before you can fetch a Vehicle JWT. DIMO Connect handles vehicle sharing.
3. Exchange the Developer JWT for a Vehicle JWT by sending a request to the Token Exchange API at `https://token-exchange-api.dimo.zone/v1/tokens/exchange`. Include the Golf's token ID, the contract address `0xbA5738a18d83D41847dfFbDC6101d37C69c9B0cF` and the permissions you need. Request the all-time, non-location data permission (privilege `1`), since the query below returns timestamps and segment locations and you should confirm which permissions your use case needs.
4. Send the Vehicle JWT in the `Authorization` header of a GraphQL request to the Telemetry API at `https://telemetry-api.dimo.zone`.
5. Call the `segments` query with `mechanism: idling`, the Golf's `tokenId`, and a `from`/`to` range of at most 31 days.
6. Tune detection with `config` if needed. `maxIdleRpm` sets the upper RPM bound for idle (default 1000, min 300, max 3000). `minSegmentDurationSeconds` filters short segments (default 240). `signalCountThreshold` sets how sensitive activity detection is (default 10).
7. Read each segment's `duration` (in seconds), `start` and `end`. If `isOngoing` is true, the segment extends past your query range and `end` is not included.
8. Page through results with `limit` (default 100, max 200) and `after`, passing the start timestamp of the last segment from the previous page.

## Code

This GraphQL query is adapted from the Telemetry API `segments` documentation. Replace `<vehicleTokenId>` with the Golf's token ID and send your Vehicle JWT as `{ "Authorization": "<yourVehicleJwt>" }`.

```graphql
query GetIdlingSegments {
  segments(
    tokenId: <vehicleTokenId>
    from: "2025-11-01T09:21:19Z"
    to: "2025-11-07T09:21:19Z"
    mechanism: idling
    config: {
      maxIdleRpm: 1000
      minSegmentDurationSeconds: 240
    }
    signalRequests: [
      { name: "powertrainCombustionEngineSpeed", agg: AVG }
      { name: "speed", agg: MAX }
    ]
    limit: 50
  ) {
    start {
      timestamp
      value { latitude longitude }
    }
    end {
      timestamp
      value { latitude longitude }
    }
    duration
    isOngoing
    startedBeforeRange
    signals { name agg value }
  }
}
```

## FAQ

### Does idling detection work without a DIMO device?
No. The documentation states that the `idling` detection mechanism requires a DIMO device. On a Volkswagen Golf, the DIMO LTE R1 and AutoPi both list idling.

### Which Golf signals does idle detection rely on?
Idle segments are based on engine RPM staying in the idle range. Both the DIMO LTE R1 and AutoPi report engine RPM as `powertrainCombustionEngineSpeed` on a Volkswagen Golf.

### How do I change what counts as idle?
Set `maxIdleRpm` in `config`. Windows where the maximum RPM is at or below this value are considered idle. The default is 1000, with a minimum of 300 and a maximum of 3000.

### How far back can I query?
The maximum date range for a `segments` query is 31 days. Use `limit` and `after` to page through results within that range.

### Why is a segment missing an end time?
If `isOngoing` is true, the segment extends beyond your query range, so `end` is not included. Widen the `to` time or query again later.
